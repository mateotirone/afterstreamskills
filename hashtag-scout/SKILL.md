# Hashtag scout

## Inputs
Game or category, clip type (funny, clutch, fail...), platform, audience (age range, region, interests), and creator size.

## Steps
1. Build three tiers:
   - Broad (1): huge tags like #gaming or the game name.
   - Niche (2 to 3): game plus content type, for example #iracingcrash or #r6clips.
   - Community (1 to 2): tags the game's own community uses, and creator-specific ones.
2. If web search is available, check what the top recent posts in this niche use, and drop tags that are spammy or banned.
3. Smaller creators should lean niche. Broad tags bury them.
4. Never pad to 30 tags. 3 to 6 that fit beat a wall of them.

## Output
A ranked list per platform with a reason for each tag, plus 2 tags to test this week.
