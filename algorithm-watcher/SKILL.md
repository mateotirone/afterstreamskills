# Algorithm watcher

## Steps
1. For each platform the creator uses (YouTube, Shorts, TikTok, Reels, X), find the most recent public guidance: official creator blogs, platform statements, and well-sourced creator research. Use web search and note the date of every source.
2. Pull out what matters now: retention and rewatch, the first 2 seconds, length sweet spots, posting frequency, originality rules (reposts and watermarks), and how hashtags are used.
3. Separate confirmed facts from creator folklore, and label which is which.
4. Turn it into actions for this creator.

## Output
Per platform: 3 to 5 current rules with source and date, then "What to change this week", at most 5 actions. Flag anything older than 6 months as possibly stale.
